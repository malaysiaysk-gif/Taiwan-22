TOCFL Band A-B 文法メタマトリクス

検定試験で高頻度で狙われる識別問題・構造差・副詞・補語体系を網羅。

① 構造助詞「的・得・地」の役割・語順比較 (TOCFL超重要)

助詞 文法パターン 機能と役割 代表例
的 (de) 修飾語 ＋ 的 ＋ 名詞 定語（名詞修飾） / 所有 / 代名詞化 認真的態度 / 台灣買的
得 (de) 動詞/形容詞 ＋ 得 ＋ 補語 様態補語 / 程度補語 / 可能補語 擔心得要命 / 笑得肚子痛
地 (de) 形容詞句 ＋ 地 ＋ 動詞 状語（動作の行われ方を描写） 認真地工作 / 客客氣氣地問

② 程度補語（強調・極限表現）のニュアンスマトリクス

〜得要命 (de yàomìng)
「死ぬほど/たまらなく〜だ」

形容詞・感情動詞に接続。強い感情や身体的苦痛・不満を吐露する強力な口語表現。

例：擔心得要命、忙得要命
〜得很 (de hěn)
「非常に〜だ / とても〜だ」

形容詞の後に置き客観的かつ力強く状態を評価。書面・口語ともに頻出。

例：水深得很、大得很
〜死了 (sǐ le)
「〜で死にそうだ」

口語で最も多用される誇張表現。マイナス状態（熱、累、餓）に接続しやすい。

例：熱死了、累死了

③ 頻度副詞の対比 (總是 vs 老是 vs 一直)

  • 總是 (zǒngshì)：いつも、常に（客観的・ニュートラル〜褒め文）
  • 老是 (lǎoshì)：いつも、しょっちゅう（不満・愚痴・非難の感情）
  • 一直 (yìzhí)：ずっと、連続して（途切れず継続している）

④ 選択の「還是」vs「或者」(TOCFL識別問題最頻出)

還是 (háishì) 【疑問文専用】

二者択一で尋ねる：「Aですか、それともBですか？」

你是台灣人，還是日本人？

或者 (huòzhě) 【平叙文専用】

並列条件：「AまたはB、あるいは」

我喝咖啡或者茶都可以。

  • 來得及 / 來不及
    時間に間に合う / 間に合わない
  • 做得到 / 做不到
    やり遂げられる / できない
  • 搭上 / 沒搭上

  • 形容詞 AABB

  • 才 (cái)

  • 就 (jiù)
    条件を満たせば「すぐに・容易に〜だ」

質疑応答・専門深掘り解説ノート

「左右」音響・発音メカニズム、結果補語「關掉 vs 關上」の機能的違い、電源ONの補語バリエーション。

音響・発音メカニズム 「左右 (zuǒyòu)」が日本語の「ぞーよー」と異なり区切れて聴こえる3つの理由

1. 母音の独立性と口型

zuǒ の語尾母音 [o] で一度口の形が完成し、yòu の開始音 [y (ㄧ)] へ滑り替わるため、各音節が物理的に独立して聞こえます。

2. ピッチの劇的な跳ね上がり

zuǒ（半三声：声の底の最低音）から yòu（四声：最高ピッチからの急降下）へ声帯を一気にジャンプさせるためポーズが生じます。

3. 数量の区切りポーズ

「七千步左右，才健康」のように「左右」直後は意味の境界（息継ぎ）となるため yòu が短く明瞭に発音されます。

結果補語の機能差 「關掉 (guān diào)」vs「關上 (guān shàng)」の機能的使い分け

關掉 (guān diào) ＝ 電源・機能のオフ

補語「掉」は「消失・離脱・停止」を表す。電化製品、音、水などの機能を停止させる。

  • • 關掉電視 (テレビの電源を切る)
  • • 關掉鬧鐘 (目覚まし時計を止める)
  • • 關掉冷氣 (エアコンを切る)
關上 (guān shàng) ＝ 物理的密閉・閉鎖

補語「上」は「接触・結合・閉じる」を表す。開いているドアや窓などをぴったり閉める。

  • • 關上門 (ドアを閉める)
  • • 關上窗戶 (窓を閉める)
  • • 關上盒子 (箱の蓋を閉じる)

対義・機能ON表現 「關掉（電源OFF）」に対する「機能ON」の動詞・補語バリエーション

1. 打開 / 開

最も基本的。家電や照明のスイッチを入れる。

打開電視 / 開燈

2. ～起來 (qǐlái)

動作・機能の立ち上がり・始動。

動起來 / 熱起來

3. ～上 (shàng)

回線・回路の結合・オンライン化。

連上 Wi-Fi / 接上電源

4. 開啟 (kāiqǐ)

スマホやPC設定の機能「有効化」。

開啟藍牙 / 開啟定位

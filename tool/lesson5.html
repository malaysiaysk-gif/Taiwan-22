① 目的語の性質による「数量補語」語順パターン

パターン 基本語順構造 適用できる目的語の種類 特徴・解説 代表例
パターン a 動詞 ＋ 目的語 ＋ 動詞(＋了) ＋ 数量補語 一般名詞 / 人称代名詞 動詞を2回繰り返す標準形。離合詞でも必須の形。 我洗手洗了兩次。
我等他等了半個小時。
パターン b 動詞(＋了/過) ＋ 数量補語(＋的) ＋ 目的語 一般名詞 / 地名 数量補語を目的語の前に置く。時量補語では「的」を伴うこともある。 看過兩、三次牙齒。
看了兩個小時的報紙。
パターン c 動詞(＋了/過) ＋ 目的語 ＋ 数量補語 人称代名詞 / 地名（※限定） 目的語を動詞と数量補語で挟む。人称代名詞は原則この位置。 見過妳一次。
回日本一趟。

② 数量補語の2大分類：動量補語（動作回数） vs 時量補語（継続時間）

【動量補語】動作の回数・プロセス
  • ・次 (cì)：最も一般的な動作の回数（1回、2回）。
  • ・遍 (biàn)：最初から最後までの全行程を1回（もう一度繰り返す）。
  • ・趟 (tàng)：往復の移動回数（1往復、1回行ってくる）。
  • ・場 (chǎng)：試合や演劇・大雨などイベントの1回。
【時量補語】動作の継続時間長
  • ・分鐘 / 小時 / 天 / 年：動作がどれくらい続いたかの時間幅。
  • ・「了」の位置に注意：動詞の直後に置く（我用了四年）。
    ※「我用四年了」と文末に置くと「使い始めて4年になる（現在も進行中）」の意味に変わる。

TOCFL 超頻出問題 ❌ なぜ「我見過一次你」は文法的に大間違いなのか？

目的語が人称代名詞（你、我、他、她、您）の場合、パターンb（動詞＋数量補語＋目的語）の語順を使うことはできません。

必ずパターンc（動詞＋人称代名詞＋数量補語）にするか、パターンa（動詞重複形）にしなければなりません。

❌ 我 見過 一次 妳。
⭕️ 我 見過 妳 一次。（パターンc）
⭕️ 我 等 他 等了 半個小時。（パターンa：動詞重複）

感覚比較 💡 「再說一次」と「再說一遍」はどう違う？

「次 (cì)」は単に動作の発生回数を示します（一部だけでも1回と数えます）。

一方「遍 (biàn)」は「最初から最後までの全プロセス（一通り）」を強調します。「請再說一遍」は「言った内容のはじめから終わりまでを、もう一度最初から通して言ってください」という丁寧で完全なリピートを要求する表現です。
